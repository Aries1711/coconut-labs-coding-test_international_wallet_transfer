# ai_specs

One file per GitHub issue, `ISSUE-<n>-<slug>.md`, created **at the same time as
the issue** and updated through to merge.

Use `TEMPLATE.md`. The file tracks one issue's whole life: what was asked, how
scope changed and who asked for it, decisions taken while implementing, and how
it closed out.

The valuable parts are the scope changes and the decisions. An issue spec that
only restates the issue body is not worth keeping.
