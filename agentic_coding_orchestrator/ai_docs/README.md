# ai_docs

Durable design documents: the technical plan, architecture, schema and
algorithm design. Written when a design is created and updated when it changes.

| File | What it is |
| --- | --- |
| `architecture.md` | **The convention.** Layering, dependency rules, where each kind of file goes, how to add a feature. Read this before writing code. |
| `technical-plan.md` | The plan as approved during the timed build. Superseded on file layout only. |
| `original-brief.md` | The prompt the project was built from, preserved verbatim. |

A document here answers *why the design is this way*. If it only describes
what the code already says, it does not belong.
