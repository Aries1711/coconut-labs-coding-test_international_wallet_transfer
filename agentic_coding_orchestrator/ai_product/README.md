# ai_product

Product knowledge: what this wallet is meant to be, the vocabulary its rules are
written in, and the product decisions behind behaviour that would otherwise look
arbitrary in the code.

The sibling folders cover *how* the thing was built. This one covers *what it is
supposed to do and why*, so a reader can tell a deliberate rule from a bug.

| File | Holds |
| --- | --- |
| `product-brief.md` | The product in one page: who it serves, what is in scope, what is explicitly not |
| `domain-glossary.md` | The nouns and rules the code is named after — minor units, ledger, transfer vs. conversion |
| `user-journeys.md` | Each flow end to end, including what the user sees when it is refused |
| `product-decisions.md` | Choices that were judgement calls, the alternative rejected, and the open questions |
