# ai_logs

One file per day, `YYYY-MM-DD.md`. Decisions, corrections and mistakes,
written as they happen.

Write an entry when:

- a decision was made and an alternative rejected — record the reason
- something broke — record the **root cause**, not just the fix
- the owner changed the scope or overruled an approach
- an assumption turned out to be wrong

Do not write a narration of commands or a restatement of the diff. The test of
a good entry: a future reader learns something the repository cannot tell them.
